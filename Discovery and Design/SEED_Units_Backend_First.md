# Backend-First SEED Units

| SEED-ID: backend-foundation-01  \nGoal (1-2 lines): Establish backend foundations for form templates, dynamic links, trigger ingestion, static demo auth (login/logout), and SQLite persistence.  \nScope: in-scope = template CRUD, trigger event intake, single-use links, role-scoped auth/session endpoints, SQLite migrations/seeds; out-of-scope = analytics and AI inference.  \nConstraints: perf = form fetch under 300ms local p95; security = single-use token + expiry; BC = additive APIs only; cost = local-only dependencies.  \nAcceptance criteria:  \n- Given a valid trigger event, when ingested, then a form instance is created and a unique tokenized link is generated.  \n- Given a used token, when submit is retried, then request is rejected as duplicate.  \n- Given static demo logins, when calling role-protected endpoints, then role rules are enforced.  \n- Given a user logs in/out, when session APIs are called, then access state changes correctly.  \nEvidence required: migration logs, seed output, API contract tests for auth/forms/triggers/tokens, sample audit entries.  \nRisks & rollback: risk = token misuse; rollback = disable link issuance via config and revert API deployment.  \nSpec link: openspec/changes/seed-backend-foundation-01/specs/feedback-platform/spec.md |
