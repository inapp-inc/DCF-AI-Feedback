## Run the demo

```bash
# Terminal 1 — API
cd codebase/backend && cp .env.example .env && npm install
npm run demo:reset   # migrate, seed, smoke tests
npm run dev

# Terminal 2 — UI
cd codebase/frontend && npm install && npm run dev
```

Open `http://localhost:5173` — staff login `admin_demo` / `demo`. Partner portal: `/portal`. Public survey: link from Send Survey or scheduler.

## Walkthroughs

### 1. Mandated reporter journey

1. Login → iFamilyNet → MR card shows scheduler status when seeded jobs exist.
2. **Send Survey** or wait for auto-dispatch (demo fires within seconds when `DEMO_FAST_TRIGGERS` is on).
3. Open `/survey/{token}` (no auth) → complete Likert + comment → submit with AI disclosure.
4. Staff: iFamilyNet **Submit demo response** or supervisor queue in Admin.

### 2. Foster parent milestone

1. iFamilyNet placement section → FP milestone **Send Survey**.
2. Portal → Foster Parents → open link.
3. Admin → Dashboard completion by group; filter **foster_parent**.

### 3. Admin triage

1. Admin → Queue console → select row → **Load AI rationale**.
2. Reports tab → **Weekly brief** (HF draft).
3. Notifications tab — demo sink entries.
4. Equity tab — disaggregated demo demographics.

## Docker (production VM)

- **One container** (`docker/Dockerfile.app`): Node API + nginx for static UI.
- Nginx site config: **`/etc/nginx/http.d/default.conf`** (generated by `docker/start.sh`). Main config: `docker/nginx.conf`.
- **Do not** use `/etc/nginx/conf.d/` or host bind-mounts for nginx config (removed).
- Host: `/var/www/dcf-feedback`, port **4020**, path prefix **`/dcffeedback`**.

## Open risks

- HF latency on report generation; use fallback templates when provider is down.
- Public tokens are demo-grade (expiry + single-use); not production security.
- Scheduler uses in-process interval, not distributed cron.
